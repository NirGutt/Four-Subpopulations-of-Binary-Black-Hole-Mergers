# Supporting data for the paper: 

# Revealing Four Subpopulations of Binary Black-Hole Mergers with the Fifth Gravitational-Wave Transient Catalog

This repository contains supporting data and is intended to document the population-model choices used in the paper. 

## Contents

### Prior ranges

The prior ranges for the two population models are provided in:

- [Physical-spin model prior ranges](priors/phys-spin.md)
- [Effective-spin model prior ranges](priors/effective-spins.md)

These files list the prior ranges for the mass, redshift, and spin hyperparameters used in the four-component population model.

### Corner plots

Posterior corner plots for the population hyperparameters are provided in:

- [Corner plots](corner_plots/)

The corner plots show the inferred posterior distributions for the main hyperparameters of the physical-spin and effective-spin analyses.

## Component naming

The four components used throughout the support files are:

| Component name | Description |
|---|---|
| Low-mass | Compact low-mass component near `m1 ~ m2 ~ 10 Msun` |
| Horizontal | Unequal-mass component with `m2` concentrated near the low-mass scale |
| Diagonal | Intermediate-mass, near-equal-mass component |
| High-mass | Upper-mass component extending to broader mass ratios |
